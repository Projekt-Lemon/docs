## Check the status

If the bot or dashboard does not respond, check [status.projektlemon.de](https://status.projektlemon.de) for current outages.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The bot can't assign or remove a role">
    Discord only lets bots manage roles below their own role. Open **Server Settings > Roles** and drag the Projekt Lemon role above every role it should manage. Also check that the bot still has the **Manage Roles** permission.
  </Accordion>

  <Accordion title="My server doesn't appear in the dashboard">
    You need the **Manage Server** permission on that server. Make sure you are signed in with the right Discord account.
  </Accordion>

  <Accordion title="Slash commands don't show up">
    Make sure the bot is on your server and has permission to use application commands in that channel. Restarting Discord can also help.
  </Accordion>
</AccordionGroup>
