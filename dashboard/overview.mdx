The web dashboard at [projektlemon.de](https://projektlemon.de) is the central place to configure Projekt Lemon. Every module can be managed there without memorizing commands.

## Sign in

1. Open [projektlemon.de](https://projektlemon.de).
2. Sign in with your Discord account.
3. Select the server you want to manage. Only servers where you can manage the server are listed.

## What you can configure

| Area | What it does |
| --- | --- |
| [Welcome messages](/modules/welcome-messages) | Embeds with variables for new members |
| [Tickets](/modules/tickets) | Panels, categories, transcripts and Ticket AI |
| [Verification](/modules/verification) | Verify button and verification role |
| [Security](/modules/security) | Anti-raid, auto-mod, honeypot, ghost ping logs |
| [Leveling](/modules/leveling) | XP, levels and rank cards |
| [Embed maker](/modules/embed-maker) | Embeds with Discord buttons |
| [Community tools](/modules/community-tools) | Giveaways, forms, team list, TempVoice, voice support |
| [Autoresponder](/modules/autoresponder) | Automatic replies to trigger words |
| [Server stats](/modules/server-stats) | Live statistics as voice channels |
| [Server tag](/modules/server-tag) | Role for members with your tag in their status |
| [Premium](/premium/overview) | Unlock Premium for 4,99 € per month |
| [Custom bot](/premium/custom-bot) | Name, avatar, status and activity of your own bot |

<Info>
  Changes you save in the dashboard apply to the bot on your server. If the bot does not react, check the [status page](https://status.projektlemon.de).
</Info>
