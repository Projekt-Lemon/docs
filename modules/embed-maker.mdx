The embed maker lets you build Discord embeds without writing code, for announcements, rules or info channels.

## Send an embed

1. Open the [dashboard](/dashboard/overview) and select your server.
2. Open **Embed maker**.
3. Fill in the fields you need:
   - Title
   - Description
   - Color (default `#a855f7`)
   - Thumbnail URL
   - Image URL
   - Footer text and footer icon
4. Choose a channel and send it.

## Saved embeds

You can save up to 100 embeds per server with a title, description, color and footer. Saved embeds can be edited, deleted and selected as a response in the [autoresponder](/modules/autoresponder).
