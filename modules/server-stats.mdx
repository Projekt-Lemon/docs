---
title: "Server stats"
description: "Show live server statistics as locked voice channels in a category."
---

Server stats creates voice channels whose names show live numbers about your server. Members cannot join these channels.

## Available stats

| Option | Channel name |
| --- | --- |
| Members | `👥 Mitglieder: <count>` |
| Bots | `🤖 Bots: <count>` |
| Boosts | `🚀 Boosts: <count>` |
| Server name | `🌍 Server: <name>` |
| Users in voice | `🎤 Im Voice: <count>` |

The channels are updated every 15 minutes to avoid Discord rate limits.

## Set up

1. Open the [dashboard](/dashboard/overview) and select your server.
2. Open **Server stats**.
3. Select the category the channels should be created in.
4. Enable the stats you want and save.

<Note>
  The bot needs permission to create and rename channels in the selected category.
</Note>
