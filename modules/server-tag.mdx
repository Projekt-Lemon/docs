title: "Server tag"
description: "Give members a role automatically while your server tag is in their custom status."
---

The server tag module rewards members who put a text, for example your server tag, in their Discord custom status.

## How it works

- When a member adds the text to their custom status, they receive the configured role.
- When they remove it, the role is removed again.
- The check is not case-sensitive.

## Settings

| Field | Description |
| --- | --- |
| Tag text | Text that must appear in the custom status |
| Role | Role the member receives |
| Reward type | Where the thank-you message is sent: **Direktnachricht (DM)** or **Kanal** |
| Channel | Channel for the thank-you message when the reward type is **Kanal** |

## Set up

1. Open the [dashboard](/dashboard/overview) and select your server.
2. Open **Server tag**.
3. Enter the tag text, select a role and a reward type, then save.
4. Make sure the Projekt Lemon role is above the reward role in **Server Settings > Roles**.
