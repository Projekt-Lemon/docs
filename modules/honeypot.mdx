---
title: "Honeypot"
description: "Set up a trap channel, matching rule, punishment, moderation log and channel message for the Honeypot spam filter."
---

The Honeypot module turns a channel into a trap for spam bots. When someone posts a message in it that matches the rule, the bot punishes the author and logs the event.

## Settings

| Setting | Description | Default |
| --- | --- | --- |
| Enabled | Turns the honeypot on or off | Off |
| Trap channel | Channel that acts as the trap | None |
| Trigger | Regular expression a message must match | `.*` (every message) |
| Action | **Ban** (instant ban), **Kick** or **Timeout** (7 days) | Ban |
| Purge messages | With **Ban**, also deletes the user's messages from the last 24 hours | Off |
| Log channel | Channel for the moderation log | None |
| Embed title | Title of the trap channel message | `⚠️ Sicherheitsfalle / Honeypot` |
| Embed description | Text of the trap channel message | Empty |
| Embed color | Color of the trap channel message | `#ef4444` |

<Warning>
  Hide the trap channel from regular members so they do not trigger it accidentally. Bots and messages outside the trap channel are ignored.
</Warning>

## Trap-channel message

When you save with the honeypot enabled, the bot posts an embed with your title, description and color to the trap channel.

## Log entry

If a log channel is set, every catch is logged with:

- User name and ID
- Join date
- Action taken
- The triggering message (first 900 characters)
- Server name
