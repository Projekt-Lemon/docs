title: "Welcome messages"
description: "Greet new members with a custom embed and placeholders."
---

Welcome messages give new members a warm first impression. You configure the embed in the dashboard.

## Settings

| Field | Default |
| --- | --- |
| Enabled | Off |
| Channel | None |
| Embed title | `Willkommen auf {server}!` |
| Embed description | `Hallo @userping, willkommen auf **{server}**! Du bist Mitglied #{membercount}.` |
| Embed color | `#3b82f6` |
| Thumbnail URL | `{user_avatar}` |
| Image URL | Empty |
| Footer text | `Projekt Lemon • {server}` |
| Footer icon | `{server_icon}` |

## Variables

| Variable | Replaced with |
| --- | --- |
| `@userping` | Mention of the new member |
| `@user` | Display name |
| `{username}` | Username |
| `{server}` | Server name |
| `{membercount}` | Member count |
| `{user_avatar}` | Avatar URL of the member |
| `{server_icon}` | Server icon URL |

## Set up

1. Open the [dashboard](/dashboard/overview) and select your server.
2. Open **Welcome messages** and enable the module.
3. Choose the channel where the message should be posted.
4. Design your embed with the variables above, then save.
