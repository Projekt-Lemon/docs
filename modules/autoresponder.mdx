title: "Autoresponder"
description: "Reply automatically to trigger words with a text message or a saved embed."
---

The autoresponder replies automatically when a message contains a trigger.

## Rules

Each rule has three parts:

| Field | Description |
| --- | --- |
| Trigger | Word or phrase that starts the reply |
| Response type | **Normale Nachricht** (text) or **Ausgewähltes Embed** (a saved embed from the [embed maker](/modules/embed-maker)) |
| Response | The text, or the embed to send |

You can create up to 50 rules per server. Rules without a trigger are ignored when you save.

## Set up

1. Open the [dashboard](/dashboard/overview) and select your server.
2. Open **Autoresponder**.
3. Add rules and save.
